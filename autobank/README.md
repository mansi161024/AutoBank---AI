# AutoBank AI - Autonomous Financial AI Platform

AutoBank AI is an enterprise-grade autonomous AI banking platform that combines personal financial management, automated budgeting, smart loan & bill tracking, emergency survival planning, government scheme discovery, and multi-agent AI financial advisors.

## 🚀 System Architecture

```
autobank/
├── frontend/    # React SPA with Redux Toolkit, Recharts, and Modern Glassmorphism UI
├── backend/     # Express.js REST API with Mongoose, Auth JWT, and AI Agent workflows
├── database/    # SQL database schemas, migration scripts, and ER models
└── docs/        # Architectural specifications, API docs, and AI workflow guides
```

## 🛠️ Quick Start

### 1. Backend Setup
```bash
cd backend
npm install
npm run dev
```

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```

## 🤖 AI Subsystem Capabilities
- **Financial Advisor Agent**: Multi-turn financial advice and portfolio analysis.
- **Budget Agent**: Autonomous dynamic budget generation and expense velocity tracking.
- **Bill Agent**: Automated subscription tracking & renewal alerts.
- **Loan Agent**: Smart amortization & early pay-down strategies.
- **Savings Agent**: Automated goal projection & micro-savings triggers.
- **Survival Agent**: Emergency runway calculation & crisis financial planning.
- **Document Agent**: KYC verification & financial statement parsing.
- **Scheme Agent**: AI matchmaker for government subsidies & financial programs.
